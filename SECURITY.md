# Security Policy

## Supported Versions

This Android client is in prerelease. Security reports are triaged against the
most recent published build and the current `staging` branch. If you can only
reproduce the issue on an older build, include the exact version or commit.
Find prereleases in [GitHub Releases][releases].

## Reporting a Vulnerability

If you find a vulnerability in the Android client or code maintained in this
repository, [submit a private report on GitHub][report].

Include the affected component, the build or commit, the Android version, and
the potential impact. Include enough information for maintainers to verify the
behavior in a test environment. Remove credentials, session tokens, and personal
data from logs or attachments.

Keep vulnerability details out of public issues and pull requests while
maintainers review the report. Follow-up questions and disclosure coordination
can stay in the private GitHub report.
