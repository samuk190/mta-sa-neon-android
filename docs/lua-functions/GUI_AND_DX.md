# GUI & 2D/3D Drawing (DX & CEGUI)

2D screen drawing, fonts, text, rectangles, lines, textures, render targets, GUI windows, buttons, edits, labels, gridlists, and 3D line drawing.

## Binding Coverage

- **Total Functions:** 199
- **Nonconstant handlers:** 199 (100.0%)
- **Stubs:** 0
- **Missing:** 0

> **Technical Requirement:** Desktop uses CEGUI and Direct3D9. Mobile uses `MtaDxView.java` (Android Canvas) + `LuaGuiApi.cpp`. Resource GUI fonts load through Android Typeface, are distinct from DX fonts, and detach from widgets on destruction/resource stop. GUI labels honor alignment, wrapping, clipping and logical lines; label metrics use the assigned font. Built-in GUI font names use Android system faces, so their appearance and CEGUI skin geometry still differ. Edit/memo input and caret count Unicode characters; JNI converts UTF-16/UTF-8. Memo Enter inserts a newline; logical lines render separately. The eight 2D draw calls honor postGUI, capture blend/font state and retain render-target order. DX text supports alignment, clipping, wrapping, independent numeric scales and rotation with a pivot; Canvas font metrics still differ from Direct3D. Primitive lines interpolate vertex colors. All 199 names now have nonconstant handlers; this is binding coverage, not full compatibility. Native 3D is limited to postfx, model 2DFX mutation to light/sun-glare, and shaders to a supported single-pass DX image subset using isolated EGL/GLES and bitmap readback. Grid sorting, selection, memo wrapping/automatic caret scrolling and the documented native/shader gaps remain pending. Host tests and Android compilation do not verify device rendering.
